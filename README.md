**denc** (decode/encode) is a Python wrapper for FFmpeg


## Installation
### Conda environment
 `conda create -n m python=3.14`

### Python packages

**Release**:
```bash
pip install -r requirements.txt
```

**Development**:
```bash
pip install -r requirements-dev.txt
```

### External packages: FFmpeg
- FFmpeg: `python denc/install.py`
